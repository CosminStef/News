# Daily Briefing

An automated personal news briefing, published daily as a static web page (GitHub Pages).

- `index.html` — the latest edition (today).
- `arhiva/` — past editions, one file per day (`YYYY-MM-DD.html`), with an index.
- `manifest.json` — PWA manifest so the page can be added to an iPhone home screen as an app ("Briefing").

Categories: Dental, AI, Technology, Psychology, Education, Medicine, Economy, Politics. Each item carries a confidence label (Verified / Partial / Unverified) and source links.
